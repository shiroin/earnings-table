# 決算比較表メーカー

企業マスター（各社の *_company_master）と Googleスプレッドシートの決算データから、ロゴ入りの決算比較表・セグメント表（PNG）を作るWebアプリです。

**公開URL:** https://shiroin.github.io/earnings-table/

## できること
1. スプレッドシートを読み込む（共有設定「リンクを知っている全員（閲覧者）」）
2. 表に入れる企業を選ぶ（発表日・市場で絞り込み）
3. 数字を確認・修正、または手入力で企業を追加
4. タイトル・単位・期の表示などを整えて PNG をダウンロード

表の列: 企業 | 売上高 | 前年同期比 | 営業利益 | 前年同期比 | 営業利益率 | 時価総額

コマンドラインでも同じ画像を作れます: `python3 render.py 決算.csv -o 決算.png --title "…" --palette teal`

## スプレッドシートの構成
| シート | 列 |
|---|---|
| ウォッチリスト | 企業, 市場(JP/US/KR/TW/CN), コード, ドメイン, ロゴ指定, メモ, 社名表示(○) |
| 決算データ | 発表日, 市場, 企業, 期, 単位, 売上高, 売上高前年比, 営業利益, 営業利益前年比, 営業利益率, 時価総額, 出典, 入力 |

毎朝の自動まとめ（別リポジトリ）が「決算データ」に追記します。

## 見た目
「見た目を整える」で配色（6種類＋自由な色）、期の表示位置、マイナス記号を選べます。
ロゴだけでは分かりにくい企業は、カードの「ロゴの下に社名」にチェック（ウォッチリストの「社名表示」列に ○ を入れておくと最初からチェックされます）。

## ロゴ
`logos/` にあるロゴを企業名で自動表示します（`logos/index.json` が対応表）。
GitHub Actions「ロゴ取得」がマスター同期のたびに、ウォッチリストに増えた企業のロゴを取得します。すぐ取りたいときは Actions タブから手動実行。
ロゴが違うときは、`logos/overrides.csv` に「企業（英語名）,ロゴ指定（画像URL か wiki:ファイル名.svg）」を足し、そのロゴファイルを消してから「ロゴ取得」を手動実行してください。
アプリ上で「ロゴ画像を選ぶ」から一時的に差し替えることもできます。

## 企業マスターとの連携
- ウォッチリスト: スプレッドシート `global_company_watch_300` シート（`config.json` の `watchlist`）。No. があり、本拠地かマスターが入っている行が対象。
- 各社の数字: ウォッチリストの「Financials」列のマスター（xlsm / xlsx / スプレッドシート）から読む。
  - `会社全体_四半期` の revenue / operating_profit。一番下の行が最新。期は「FY2027Q2」→「Q2」と表示。
  - 前年同期比は、同じ四半期の前年度の行から計算。
  - `セグメント売上高_四半期` / `セグメント利益_四半期` からセグメント表を作れる（表示名・色は「設定」シートの セグメント 行）。
  - 単位: マスターの数値は百万（input_currency）。表示は「設定」の display_unit（億・兆など）。
- 同期: GitHub Actions「企業マスター同期」が2時間ごとに `data/masters.json` を更新（Actions タブから手動実行も可）。
- ウォッチリストとマスターは「リンクを知っている全員（閲覧者）」で共有しておくこと。
- `data/masters.json` は公開リポジトリにあるため、誰でも閲覧できます。
