# 決算比較表メーカー

Googleスプレッドシートの決算データから、ロゴ入りの決算比較表（PNG）を作るWebアプリです。

**公開URL:** https://shiroin.github.io/earnings-table/

## できること
1. スプレッドシートを読み込む（共有設定「リンクを知っている全員（閲覧者）」）
2. 表に入れる企業を選ぶ（発表日・市場で絞り込み）
3. 数字を確認・修正、または手入力で企業を追加
4. タイトル・単位・期の表示などを整えて PNG をダウンロード

表の列: 企業 | 売上高 | 前年同期比 | 営業利益 | 前年同期比 | 営業利益率 | 時価総額

コマンドラインでも同じ画像を作れます: `python3 render.py 決算.csv -o 決算.png --title "…" --palette teal`

## スプレッドシートの構成
| シート | 列 |
|---|---|
| ウォッチリスト | 企業, 市場(JP/US/KR/TW/CN), コード, ドメイン, ロゴ指定, メモ, 社名表示(○) |
| 決算データ | 発表日, 市場, 企業, 期, 単位, 売上高, 売上高前年比, 営業利益, 営業利益前年比, 営業利益率, 時価総額, 出典, 入力 |

毎朝の自動まとめ（別リポジトリ）が「決算データ」に追記します。

## 見た目
「見た目を整える」で配色（6種類＋自由な色）、期の表示位置、マイナス記号を選べます。
ロゴだけでは分かりにくい企業は、カードの「ロゴの下に社名」にチェック（ウォッチリストの「社名表示」列に ○ を入れておくと最初からチェックされます）。

## ロゴ
`logos/` にあるロゴを企業名で自動表示します（`logos/index.json` が対応表）。
GitHub Actions「ロゴ取得」が毎日、ウォッチリストに増えた企業のロゴを取得します。すぐ取りたいときは Actions タブから手動実行。
ロゴが違うときは、ウォッチリストの「ロゴ指定」列に画像URL か `wiki:ファイル名.svg` を入れて、「取得済みのロゴも取り直す」にチェックして手動実行してください。
アプリ上で「ロゴ画像を選ぶ」から一時的に差し替えることもできます。
